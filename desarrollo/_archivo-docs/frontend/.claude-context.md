## Known Issues / Workarounds

1. **Radix Checkbox + ScrollArea** - Causes infinite loop. Use react-select with isMulti instead.
2. **Date timezone** - Always use dateUtils.js, never raw Date constructor with date strings.
3. **Currency formatting** - Format only on blur to avoid concatenation bugs.
4. **Dialog overlay** - Fixed in dialog.jsx, prevents orphaned overlays when Select is inside Dialog.
