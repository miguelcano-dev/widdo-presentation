# draft-outreach — Redactar outreach personalizado para un prospecto

Genera el mensaje de contacto en frío para una organización concreta, listo para enviar.

## Contexto obligatorio (leer antes)
- `adquisicion-usa/01-GUIONES-OUTREACH.md` — plantillas base EN/ES, secuencia, cierre.
- `adquisicion-usa/reseñas-teamsnap.md` y `reseñas-sportsengine-leagueapps.md` — ganchos de queja por competidor.
- `negocio/sales/KNOWLEDGE-BASE.md` — diferenciadores oficiales de Widdo.

## Cómo ejecutar
1. Recibe el prospecto (fila de la Lista Maestra o datos sueltos): nombre, deporte, ciudad, software que usa, si es hispano.
2. Elige el **idioma**: español si es liga/club hispano; inglés si no.
3. Elige el **gancho de queja** según el competidor que usa:
   - TeamSnap → ads a quien paga / renovaciones sorpresa / soporte lento.
   - SportsEngine → fees de procesamiento / complejidad / bugs.
   - LeagueApps → ~5% por transacción / precios ocultos.
   - Gestión manual (Excel/WhatsApp/IG) → "pásate de las hojas de cálculo a algo bilingüe y simple".
4. Produce: **(a) DM corto** (IG/WhatsApp) y **(b) email en frío**, ambos personalizados con el nombre de la org + 1 detalle real (su torneo, nº de equipos, ciudad).
5. Un solo pedido: **demo online de 15 min**. Cierre con oferta design-partner (setup + migración gratis + precio fundador).

## Reglas
- Personaliza SIEMPRE `[Org]`, gancho e idioma. Nada de texto genérico.
- Email en frío = **CAN-SPAM**: identidad real, dirección física, línea de baja.
- No prometer features inexistentes; si falta algo → "está en el roadmap".
- Instagram/WhatsApp se envían a mano (sin bots).
