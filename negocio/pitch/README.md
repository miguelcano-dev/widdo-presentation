# Widdo — Preparacion de Pitch

## Documentos en este directorio

| Archivo | Para que | Cuando usarlo |
|---------|----------|---------------|
| `PITCH-SCRIPT.md` | Guion slide por slide + elevator pitches | Antes de cualquier reunion |
| `TOUGH-QUESTIONS.md` | Respuestas a preguntas dificiles de inversores | Estudiar antes de reuniones |
| `FOLLOW-UP-TEMPLATES.md` | Templates de email (cold, warm, follow-up, update) | Despues de reuniones |
| `INVESTOR-TRACKER.md` | Pipeline de inversores contactados | Actualizar despues de cada contacto |
| `DATA-ROOM-CHECKLIST.md` | Lista de documentos para due diligence | Verificar antes de reuniones |

## Orden de preparacion

1. Leer `PITCH-SCRIPT.md` y practicar frente al espejo (20 veces minimo)
2. Estudiar `TOUGH-QUESTIONS.md` — saber las respuestas de memoria
3. Llenar `INVESTOR-TRACKER.md` con primeros targets
4. Verificar `DATA-ROOM-CHECKLIST.md` — tener todo listo
5. Usar `FOLLOW-UP-TEMPLATES.md` despues de cada reunion
