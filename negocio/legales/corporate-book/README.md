# Corporate Book — Widdo Inc (Delaware C Corp)

El Corporate Book es la carpeta oficial con todos los documentos legales de la empresa.
Los inversores y el CPA lo piden como parte del due diligence.

## Documentos que deben estar aquí

### De Stripe Atlas (ya los tienes, descargar de dashboard.stripe.com/atlas)
- [ ] Certificate of Incorporation
- [ ] Bylaws
- [ ] Action by Incorporator
- [ ] IRS EIN Confirmation Letter
- [ ] 83(b) Election — Miguel (6,300,000 shares)
- [ ] 83(b) Election — Alwin (2,700,000 shares)

### Por firmar/firmados
- [ ] Founders Agreement (firmado por ambos)
- [ ] IP Assignment Agreement (firmado por Miguel)
- [ ] Promissory Note — Founder Loan (firmado por Miguel)
- [ ] Transfer Pricing Agreement (firmado por Miguel como RL de ambas)

### Board Resolutions (crear cuando se necesiten)
- [ ] Board Resolution aprobando Transfer Pricing Agreement
- [ ] Board Resolution aprobando Promissory Note / Founder Loan
- [ ] Board Resolution aprobando cualquier SAFE que se emita

### Stock Ledger (crear en Pulley.com o spreadsheet)
- [ ] Stock Ledger con:
  - Miguel: 6,300,000 shares Common Stock (fully vested)
  - Alwin: 2,700,000 shares Common Stock (reverse vesting 48 months)
  - Reserved: 1,000,000 shares (unissued)

### Para inversores (Data Room)
Cuando un inversor pida due diligence, compartir:
1. Certificate of Incorporation
2. Bylaws
3. Founders Agreement
4. Cap Table / Stock Ledger
5. 83(b) Elections
6. IP Assignment
7. Financial statements (P&L, balance)
8. Terms of Service + Privacy Policy (URLs)
