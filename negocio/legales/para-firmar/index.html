Cómo firmar

  1. Haz clic en "Abrir documento" para ver el HTML
  2. Revisa el contenido — verifica que todos los datos sean correctos
  3. Imprime a PDF: Ctrl+P → Destino: Guardar como PDF
  4. Sube el PDF a DocuSign (docusign.com → free plan permite 3 docs/mes)
  5. Agrega los campos de firma para cada parte
  6. Envía para firma electrónica
  7. Guarda el PDF firmado en negocio/legales/firmados/
